# Cah Trancista

Landing page estática criada para reposicionar a marca em uma direção azul, editorial e contemporânea.

## Abrir localmente

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com qualquer servidor HTTP estático.

## Publicação no Netlify

O arquivo `netlify.toml` na raiz define `dist` como diretório de publicação. Não há comando de build: o site já está pronto para ser servido como HTML estático.

## Contatos configurados

O objeto `SITE_CONFIG` no início de `dist/script.js` contém:

- Instagram: `@cah_trancista09`.

## Imagem autoral

`dist/assets/hero-braids-blue.png` foi gerada para este projeto com ImageGen. Prompt final: imagem macro editorial abstrata de fibras trançadas, composição horizontal com detalhe no lado direito, espaço negativo à esquerda, azul meia-noite/royal/gelo, sem pessoa, texto, logotipo ou marca d'água.
